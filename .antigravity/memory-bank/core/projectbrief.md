# Project Brief: Audiovault

## Mission
Build and maintain a powerful, self-hosted application that imports, manages, and streams music libraries from any major streaming platform.

## Vision
Audiovault aims to be the ultimate personal music server - combining the convenience of streaming platforms with the control and privacy of self-hosting.

## Core Values
- **Privacy First**: User data stays on user's infrastructure
- **Platform Agnostic**: Support all major streaming services
- **Quality Focused**: High-quality audio downloads (up to FLAC)
- **User Experience**: Beautiful, intuitive interface with real-time feedback
- **Reliability**: Robust fallback systems and error handling

## Key Features
1. **Multi-Platform Import**: Spotify, YouTube, Deezer, SoundCloud, Apple Music, Tidal, Amazon Music
2. **Smart Download System**: Automatic fallbacks, geo-restriction bypass, quality selection
3. **Watchlist & Automation**: Auto-sync, safe purge, de-duplication
4. **Personal Streaming**: Subsonic API implementation for mobile apps
5. **Modern UI**: Glassmorphism design with audio visualizer
6. **Last.fm Integration**: Scrobbling and recommendations

## Success Metrics
- Download success rate > 95%
- API response time < 500ms
- Zero data loss during sync operations
- User satisfaction (measured via GitHub stars/issues)
- Code coverage > 80%

## Target Users
- Music enthusiasts who want local control
- Self-hosters and privacy-conscious users
- Audiophiles seeking high-quality downloads
- Users with large music libraries across platforms
