# Watchlist & Automation

Audiovault automates your library management so you don't have to manually download tracks every time a playlist updates.

## Features

- **Auto-Sync**: A background scheduler checks your watchlisted items (playlists, artists, etc.) for new tracks every 60 minutes and queues them for download.
- **Safe Purge**: Automatically removes local tracks that were deleted from remote connected playlists. This feature includes a dry-run safety toggle to prevent accidental deletions.
- **Smart De-duplication**: Prevents duplicate downloads by thoroughly checking existing ID3 tags and the internal download history database.
- **Universal Search**: A single unified search bar lets you find music across all supported providers simultaneously.
